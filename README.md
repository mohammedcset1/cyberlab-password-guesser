# CyberLab – 3-Digit Password Guesser

An educational, client-side brute-force PIN guessing simulator. It tries 000 through 999 and displays progress, attempts, elapsed time, pause/resume and activity logs. No real account or external service is accessed.

## Run locally

Open `index.html` in your browser, or open the folder in VS Code and use the Live Server extension.

## Deploy to GitHub Pages

1. Create a new public GitHub repository (for example `cyberlab-password-guesser`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root and commit.
3. Go to **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, select `main` and `/(root)`, and save.
4. Wait for deployment. The URL will usually be `https://YOUR-USERNAME.github.io/cyberlab-password-guesser/`.

No build command or backend is required.
